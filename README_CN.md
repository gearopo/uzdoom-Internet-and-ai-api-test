# UZDoom NetHub v0.1 原型

这是一个“网络大厅 + 民间服务器 + 联机模组仓库 + AI 精灵”项目的 PK3 原型。

### 已放入
- F10：NetHub 设置菜单
- F11：生成 AI 精灵测试对象
- 服务器地址、模组仓库、AI API 地址、模型名等配置
- 最高 64 人的**配置入口**
- 60 个 WAD/PK3 堆栈槽位的**配置入口**
- 自动性能优化开关

### 目前没有伪装成已经完成的部分
纯 PK3 无法凭空给 UZDoom 增加完整 Internet HTTP 下载、服务器发现、
动态网络协议、无限人数网络同步或 AI API 通信。因此这些能力需要 UZDoom
引擎分支和/或外部桥接程序。

UZDoom 本身的多人网络能力和多人同步由引擎负责；这个 PK3 负责上层 UI、
规则、AI 精灵表现和配置。真正的“无限人数”应理解为服务器架构可扩展，
而不是让一个 Doom 网络帧无上限塞进玩家。

### 安全
远程下载的 WAD/PK3 必须做 SHA-256 校验、签名/白名单、版本依赖检查，
并在挂载前让玩家确认。
